# Wanted Visuals — визуальный клиент для Minecraft 1.21.1 (Fabric)

Чисто **клиент-сайд визуальный** мод: японские шляпы на игроках, смена неба и времени суток,
ESP/трейсеры, кастомное главное меню и современный ClickGUI. Никаких боевых/движковых читов —
только рендер.

## Возможности

### Visual
| Модуль | Что делает |
|---|---|
| `Kasa` | Японская соломенная шляпа (каса) над головами игроков. Формы: Sugegasa, Jingasa, Sandogasa, Halo. Настройки размера, высоты, цвета, красного канта, вращения и парения. |
| `Glow` | Контурная подсветка игроков, мобов, животных и предметов. |
| `ESP` | Боксы вокруг сущностей, отдельные цвета для игроков и мобов. |
| `Tracers` | Линии от камеры к целям. |
| `NameTags` | Свои ник-теги: масштаб, HP, дистанция, подложка. |
| `Trail` | Затухающий след за игроком. |
| `Fullbright` | Полная яркость (гамма пишется напрямую через mixin-аксессор). |
| `Zoom` | Приближение камеры с плавной мышью. |

### World
| Модуль | Что делает |
|---|---|
| `Sky` | Перекраска неба. Пресеты: Sakura, Sunset, Void, Amethyst, Aurora, Ink + свой цвет, ползунок насыщенности и пульсация. |
| `TimeChanger` | Клиентская фиксация времени суток (Рассвет / День / Закат / Ночь / свои тики). |
| `Weather` | Клиентская погода: ясно / дождь / гроза. |
| `Sakura` | Падающие лепестки сакуры вокруг игрока. |

### HUD
`Watermark` (лого + FPS + пинг), `ArrayList` (список активных модулей с градиентом и анимацией),
`Coords` (координаты и направление).

## UI

* **Главное меню** — тёмный градиент, красное «восходящее солнце» с лучами, летящие лепестки,
  крупная типографика `WANTED / 指名手配` и свои анимированные кнопки. Кнопка «Ванильное меню»
  возвращает стандартный экран (флаг сохраняется в конфиг).
* **ClickGUI** (по умолчанию `RIGHT SHIFT`) — рейл категорий с кандзи и скользящим индикатором,
  поиск по модулям, карточки с переключателями, правая панель настроек: свитчи, слайдеры,
  сегментированные режимы, HSB-цвет с ползунками оттенка/прозрачности и режимом «радуга».

Управление в ClickGUI: **ЛКМ** — вкл/выкл модуль, **ПКМ** — открыть настройки,
**СКМ** — назначить клавишу (затем нажать нужную; `Delete` — сбросить), **колесо** — прокрутка.

## Установка готовой сборки

CI собирает три варианта — в каждом уже лежит Fabric API, ставить отдельно ничего не нужно.
Скачать: вкладка **Actions → pack → последний прогон → артефакт `WantedVisuals-client`**.

| Файл | Как ставить |
|---|---|
| `WantedVisuals-Prism.zip` | **Отдельный клиент.** Prism Launcher / MultiMC → *Add Instance* → *Import from zip*. Создаётся самостоятельная сборка на Minecraft 1.21.1 + Fabric 0.16.5, основной профиль не трогается. |
| `WantedVisuals.mrpack` | Modrinth App / ATLauncher / Prism → импорт пака. |
| `WantedVisuals-mods.zip` | Для официального лаунчера: поставить Fabric 1.21.1 и распаковать `mods/` в `.minecraft`. |

Собрать сборки локально: `packaging/build-pack.sh` (нужны `curl`, `zip`, собранный jar в `build/libs`).

## Сборка

Нужен JDK 21 и доступ к `maven.fabricmc.net`.

```bash
./gradlew build          # или: gradle build
```

Готовый jar — в `build/libs/wanted-visuals-1.0.0.jar`. Кинуть в `mods/` вместе с
[Fabric API](https://modrinth.com/mod/fabric-api) для 1.21.1.

Запуск в среде разработки: `./gradlew runClient`.

CI-проверки: `build` собирает jar, `pack` формирует сборки, `runclient` запускает клиент
под xvfb и падает, если игра не дошла до главного меню.

## Конфиг

Состояние модулей, настройки и бинды сохраняются в `config/wanted.json` при закрытии ClickGUI
и при выходе из игры.

## Структура

```
wanted/
├── WantedClient.java        точка входа, события, бинды
├── config/ConfigManager     сохранение/загрузка JSON
├── module/                  Module, Category, ModuleManager
├── setting/                 Boolean/Number/Mode/Color настройки
├── modules/                 visual, world, hud модули
├── render/KasaFeatureRenderer   процедурная геометрия шляпы
├── ui/                      ClickGui, WantedTitleScreen, Render2D, Theme, Petals
└── mixin/                   небо, время, гамма, подмена главного меню
```
